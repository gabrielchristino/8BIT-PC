# Fontes recuperadas da prévia

`isa1_rev76.py` foi extraído do texto integral exibido no visualizador de código da conversa «Construir computador 8 bits», removendo a coluna visual de números de linha. O conteúdo é uma recuperação textual, sem garantia da codificação, quebras de linha e bytes do download original.

`isa1_rev76_microcode.json.fragment.txt` contém apenas a parte exibida pelo visualizador virtualizado. É um fragmento incompleto e não deve ser importado como JSON ou tratado como microcódigo completo.

As capturas correspondentes ficam em `../browser-captures/`. A auditoria REV76 pôde ser lida na interface, mas seu arquivo original não foi retido em bytes verificáveis; sua conclusão também consta da página ENG-KBD-01 arquivada. O Python recuperado depende de `isa1_rev33_microcode.json`, ainda ausente.
