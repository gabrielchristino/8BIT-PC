# ISA-1 rev 9.2 — proteção de escrita e reset
Base: rev 9.1. Reset global ideal limpa handshake e raster; epoch invalida geradores de barramento já iniciados. Alimentação insegura bloqueia acesso integrado. Não representa circuito físico nem proteção de CPU base isolada. Teste inicial falhou por retomada após WAIT sem revalidar epoch; corrigido com guarda após yield. Testes em fronteiras de eventos, não pulsos elétricos. Gerador criado mas nunca iniciado é uma nova operação; chamador deve descartar instruções antigas no reset. EEPROM e microcódigo binário pendentes. audit.py removido por reproduzir comportamento antigo.
Executar python test_safety.py, python test_async.py, python test.py, python validation.py, python keyboard.py.

Correção adicional: a segunda execução ainda falhou no corte anterior ao primeiro next(), pois geradores Python inicializam seu corpo sob demanda. bus agora captura epoch na criação e retorna _bus. Após essa alteração, 1282 casos de segurança passaram, assim como as bancadas de regressão. A proteção é do barramento integrado, não de todos os caminhos de acesso direto nem de geradores de instrução completos. A perda de alimentação sem reset explícito durante WAIT ainda exige política de recuperação global; não há simulação de pulsos parciais.

# Rev 9.3 — correções
AsyncMachine captura epoch na criação da instrução, verifica antes de cada retomada e fecha o gerador abortado. Falta de alimentação observada provoca reset global ideal. Reset inclui seleção de linha do teclado. Escrita direta via método write de AsyncMachine é rejeitada; barramento usa implementação interna da classe base. Arrays continuam acessíveis para fixtures; Machine e CPU legados não são protegidos por este contrato. Cabeçalho de teste JMP C040 e HALT em offset 0040; não é firmware definitivo. Teste test_instruction_reset.py cobre 26 opcodes, três períodos CPU, cortes em fronteiras de eventos inclusive antes da primeira retomada e após END, reset explícito ou alimentação insegura. Não cobre todas as combinações de operandos/flags nem pulsos físicos ou reset em toda borda de vídeo. Não há microcódigo binário. Execute também as cinco bancadas anteriores.
