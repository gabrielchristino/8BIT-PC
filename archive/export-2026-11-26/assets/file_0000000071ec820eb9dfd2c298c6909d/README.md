# ISA-1 9.8.4.6.6.7
Exploratory grouped prefetch, not sign-off. Reuses numerical assumptions from rev98466/check.py, not independently verified datasheets. N pixels per group, 4N oscillator ticks. Two banks of N byte registers, one displays while other fills. VGA addresses at 0,2,... ticks; capture at 1,3,...; CPU address/OE off at 2N, driver on at 2N+1, WE low at +2, high at +3, driver off at +4. CPU read alternative keeps OE on, captures at +2 and disables at +3. One CPU transaction per group. N=2 fails turnaround; N=4 and 8 pass baseline but video setup only 0.722 ns. Address generation delay not independently included; command uncertainty 8 ns is hypothetical. Improve by capturing later within two ticks, with explicit hold and next address checks. Raster test is abstract snapshot accounting, not event-level FIFO or CDC simulation; first group is initialized at line start (physical prefetch during previous blanking required). Writes after prefetch become visible on later fetch; tearing possible. Separate write driver and read holding register recommended. No physical approval, no prior files changed.
